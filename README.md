# Alpine.js 日本語ドキュメント

Alpine.js公式ドキュメントの非公式日本語版です。

## 現在の構成

- upstream: `alpinejs/alpine` の `main`
- 原文: `upstream/docs/`
- 日本語訳: `docs/`
- 同期位置: `.upstream-version`
- 翻訳ルール: `config/translation-rules.md`
- 用語集: `config/glossary.yml`
- 公開基盤: VitePress
- 現在の翻訳対象: `essentials/installation.md`

公式サイト固有の実行デモは、現時点では再現しません。

## 開発

```shell
npm install
npm run docs:dev
npm run docs:build
```
